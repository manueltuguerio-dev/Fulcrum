MX Supply Assurance

Riesgo de faltante por numero de parte y consolidado por proveedor

Archivos de entrada

Deja en una carpeta de Drive el libro MX y el archivo Data del mes. El script los convierte a Hojas de calculo sin modificar los originales, y borra las copias al terminar.

El archivo cuyo nombre contenga data se toma como el export de partes; el otro .xlsx de la carpeta se toma como el libro MX.

Ventana de riesgo

Define en que semanas cuenta el rojo. El rojo es la proyeccion negativa, el mismo < 0 del formato condicional del libro.
